# Off-Page 30-Day Execution Plan

## Date Window
March 24, 2026 to April 22, 2026

## Goal
Increase qualified organic demand through placements, mentions, backlinks, and referral traffic from enterprise-relevant channels.

## Milestones
1. Days 1-5: submission + tracking baseline complete.
2. Days 6-12: outreach wave 1 live (roundups/newsletters/podcasts).
3. Days 13-20: partner co-marketing pipeline active.
4. Days 21-27: optimize for qualified conversions.
5. Days 28-30: lock winners and next sprint plan.

## Daily Operating Loop
1. Run `npm run growth:daily -- --day <N>`.
2. Execute directory and outreach tasks from `data/offpage/*.csv`.
3. Publish at least two distribution assets.
4. Run `npm run metrics:ingest` and update weekly scorecard.

## KPI Targets
- 20+ live placements by Day 30.
- 15+ referring domains.
- 1,500+ weekly impressions.
- 25+ organic clicks/week.
- 8+ demo-intent actions/month.
