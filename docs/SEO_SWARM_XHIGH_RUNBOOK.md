# SEO Swarm XHigh Runbook

## Objective
Create a repeatable SEO command center that combines technical fixes, CTR rewrites, and distribution output to increase qualified users.

## Model Profile
- Model: `gpt-5.4`
- Reasoning: `xhigh`
- Roles: Technical SEO Lead, On-Page + CTR Lead, Off-Page Distribution Lead, Analytics Lead

## Daily Operating Sequence
1. `npm run metrics:ingest`
2. `npm run seo:health`
3. `npm run seo:war-room`
4. `npm run seo:swarm`
5. `npm run indexnow:submit`

## Generated Artifacts
- Swarm board: `data/swarm/seo-swarm-YYYY-MM-DD.md`
- Distribution pack: `data/swarm/distribution-pack-YYYY-MM-DD.md`

## Execution Guardrails
- Fix top 5 zero-click pages first (impressions >= 5).
- Push 2+ distribution assets and 10+ outreach touches daily.
- Add internal links from high-authority pages to the top opportunity URLs.
- Re-run indexing after each metadata + linking batch.

## Weekly Targets
- Users: 5x from baseline
- Sessions: 5x from baseline
- Impressions: 2x from baseline
- Organic clicks: from 0 to 25+ per week
- Demo-intent actions: 8+ per month
