# QorSync 14-Day Distribution Sprint

## Baseline (March 23, 2026)
- Sessions (last 7d): 2
- Views (last 7d): 2
- Search impressions (last 7d): 81
- Search clicks (last 7d): 0

## Sprint Outcome Targets
- 1,000+ weekly impressions by Day 14.
- First 25+ organic clicks by Day 14.
- 15+ referring domains from directory/community/outreach work.
- 2+ pages entering average position < 15 for target keywords.

## Daily Operating Loop
1. Run `npm run growth:daily -- --day <N>`.
2. Execute the 3 daily actions listed.
3. Post and distribute the queued URLs.
4. Run `npm run indexnow:submit` after updates.
5. Submit sitemap updates in Search Console/Bing.
6. Run `npm run metrics:ingest` and log KPI movement.

## Daily KPI Guardrails
- New indexed URLs: at least 5/day.
- New social/community assets: at least 2/day.
- Outreach touches: at least 5/day.
- Internal links added on-site: at least 3/day.

## CTR Optimization Rules
- Prioritize pages with impressions > 10 and clicks = 0.
- For each target page, update title + description + above-the-fold intro.
- Add a “Related Implementation Resources” section with 3-4 internal links.
- Re-request indexing after each CTR edit batch.

## Content Cluster Rotation
- Days 1-5: Governance + approval workflow pages.
- Days 6-10: AI memory systems pages.
- Days 11-14: SPX/trading pages + tool pages.

## Escalation Triggers
- If impressions do not increase for 3 days, increase distribution volume and refresh top 5 metadata variants.
- If positions stagnate above 30, add supporting long-tail posts and internal links from high-authority pages.
- If clicks stay at 0 despite impressions > 500, run another title/description iteration with sharper benefit-led copy.
