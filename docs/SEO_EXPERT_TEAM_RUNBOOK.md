# SEO Expert Team Runbook

## Objective
Drive sustained qualified traffic growth for QorSync AI by combining technical SEO, on-page conversion intent, and off-page distribution.

## Team Roles
1. Technical SEO Lead
2. On-Page + CTR Lead
3. Off-Page + Distribution Lead
4. Analytics + Experimentation Lead

## Daily Command Center
1. `npm run metrics:ingest`
2. `npm run seo:health`
3. `npm run seo:war-room`
4. `npm run growth:daily -- --day <N>`
5. `npm run indexnow:submit`

## Role Execution

### 1) Technical SEO Lead
- Ensure sitemap and canonical coverage for all priority URLs.
- Resolve thin content, metadata quality, and indexability blockers.
- Keep internal linking paths from high-authority pages to conversion pages.
- Validate crawl and index submission every day.

### 2) On-Page + CTR Lead
- Prioritize pages with impressions but zero clicks.
- Refresh title, description, and above-the-fold messaging for top opportunities.
- Add implementation-focused internal links and CTAs.
- Maintain high-intent solution pages for buyer keywords.

### 3) Off-Page + Distribution Lead
- Execute daily distribution posts and weekly outreach waves.
- Submit and follow up directory placements.
- Run newsletter/podcast/partner outreach with UTM links.
- Track referral quality, not just referral volume.

### 4) Analytics + Experimentation Lead
- Track users, new users, sessions, views, clicks, impressions.
- Run weekly winner/loser analysis by channel and page.
- Promote winning copy templates and kill low-yield motions quickly.

## Weekly KPI Review
- Impressions growth week-over-week
- Organic clicks growth week-over-week
- Pages with position <= 20 and clicks = 0
- Referring domains added
- Demo-intent actions (tool completions, demo clicks, form starts)

## Escalation Rules
- If impressions are flat for 3 days: increase distribution output and refresh top 5 metadata variants.
- If clicks remain flat while impressions rise: run CTR rewrite sprint on top 10 impression URLs.
- If rankings stall above position 30: publish 3 support pages and add internal links from homepage/blog hubs.
