# KPI Cadence Scorecard

## Daily (15 minutes)
- Directory submissions sent
- Outreach emails/messages sent
- Replies received
- New mentions/placements
- Index requests completed
- Top page CTR movement

## Twice Weekly (Mon/Thu)
- Referring domains gained
- Tool starts/completions
- Demo-intent sessions
- Pages moving into top 20 positions

## Weekly (Friday)
- Channel ROI by qualified actions
- Top CTR winners and losers
- Outreach conversion rate by segment
- Next week priority list
